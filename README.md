# ML-Practice
# Titanic Survival Prediction Using Machine Learning

## Objective
To predict whether a passenger survived the Titanic shipwreck using historical passenger data.

## Dataset
The Titanic dataset from the Kaggle Machine Learning from Disaster competition.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Methodology
1. Loaded and explored passenger data.
2. Performed exploratory data analysis.
3. Handled missing values and encoded categorical variables.
4. Engineered family-related features.
5. Trained Logistic Regression and Random Forest classifiers.
6. Evaluated model performance using accuracy, precision, recall, F1-score, and a confusion matrix.
7. Generated predictions for a hypothetical passenger.
8. Saved the trained model for reuse.

## Conclusion
The project demonstrates how supervised machine learning can identify patterns associated with passenger survival and predict outcomes from passenger characteristics. Model performance is evaluated using a held-out test set.
